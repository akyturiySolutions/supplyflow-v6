🚀 Deployment Checklist

1. Environment Variables
Set these in Render / Railway / your server:

PORT=3000
VERIFY_TOKEN=your_secret_verify_token
WHATSAPP_TOKEN=your_meta_access_token
PHONE_NUMBER_ID=your_meta_phone_number_id
APP_SECRET=your_meta_app_secret
ADMIN_TOKEN=your_admin_dashboard_token
ADMIN_EMAIL=admin@yourbusiness.com
ADMIN_PASSWORD=strong_password_here
BUSINESS_ID=your_business_id
BIZ_NAME=Your Business Name
BIZ_SECTOR=water   # or gas/food/milk/retail
MPESA_TILL=6247361
MPESA_KEY=safaricom_consumer_key
MPESA_SECRET=safaricom_consumer_secret
MPESA_SHORTCODE=174379
MPESA_PASSKEY=your_mpesa_passkey
MPESA_ENV=sandbox  # change to production when live
APP_URL=https://yourapp.onrender.com
SUPPORT_PHONE=254712345678
FIREBASE_CONFIG={"type":"service_account","project_id":"..."}  # optional

2. WhatsApp Webhook
In Meta Developer Console → WhatsApp → Configuration:

Callback URL:  https://YOURAPP.onrender.com/webhook
Verify Token:  (same as VERIFY_TOKEN above)

Subscribe to: messages, message_deliveries, message_reads

3. Deploy to Render

  • Push code to GitHub
  • New Web Service → connect repo
  • Build: npm install
  • Start: npm start
  • Add all environment variables above

4. Multi-Tenant (SaaS)
Each business gets their own WhatsApp Phone Number ID.
Map PHONE_NUMBER_ID → bizId in Firestore businesses collection.
One server instance can handle unlimited businesses.

5. Custom Products
Add products to Firestore: businesses/{bizId}.products = [...]
Or use the API: POST /api/admin/config with products array.
